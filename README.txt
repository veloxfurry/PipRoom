PIPROOM — Python Package Manager
================================

Тёмный графический установщик Python-пакетов на CustomTkinter.
Фирменный знак PIPROOM находится в assets/piproom-mark.svg; интерфейс использует его
растровое отображение через Pillow, чтобы не требовать отдельного SVG-движка.
Основной акцентный цвет — океанский синий.

Запуск в Windows
----------------
1. Установи Python 3 с https://www.python.org/downloads/.
2. Распакуй архив в обычную папку.
3. Запусти run_windows.bat.

Скрипт проверит Python, установит CustomTkinter и откроет PIPROOM.

Возможности
-----------
- Установка одного или нескольких пакетов по имени.
- Указание версии, например pandas==2.2.3.
- Обновление уже установленного пакета.
- Обновление pip.
- Журнал вывода pip и индикатор активности установки.
- Кнопки быстрого ввода популярных пакетов.
- Отображение точного python.exe, в который выполняется установка.
- Копирование команды для просмотра пакетов именно этого Python.

Важно
-----
Установка выполняется так:
    sys.executable -m pip install ИМЯ_ПАКЕТА

Чтобы посмотреть список библиотек этого же интерпретатора, используй команду,
которую можно скопировать в боковой панели приложения.
